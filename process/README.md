# Process

Bản gốc của file dùng trong Claude Project. Sửa ở đây qua PR, rồi upload lại bản mới vào Project knowledge.

- `02-team-context.md` — bối cảnh team, vấn đề P1–P3, giả thuyết H1–H5
- `03-prompts.md` — P1–P3 nghiên cứu; V1 handoff → `handoffs/`, V2 chốt phiên → `decisions.md` + `CHANGELOG.md`, V3 khả thi → dùng `_shared/constraints.md`
- `04-learning-log.md` — nhật ký nghiên cứu, mới nhất ở trên
